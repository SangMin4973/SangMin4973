# 이상민

RAG와 LLM을 활용한 서비스를 개발합니다.

문학 속 인물과 대화하는 서비스, 강의 정보를 찾아주는 챗봇, 불법 적재 차량 탐지 시스템을 만들었습니다. 최근에는 검색 품질과 답변의 정확도를 평가하고 개선하는 데 관심을 두고 있습니다.

기능을 완성한 뒤에도 잘못된 결과가 나온 이유를 살펴봅니다. 검색과 답변을 나누어 평가하고, 개선된 부분과 아직 확인하지 못한 부분을 함께 기록합니다.

## 프로젝트

[Lecture Info](https://github.com/SangMin4973/2025-2-OpenSW-T01-lecture-info)  
강의계획서와 수강 후기를 검색하는 RAG 챗봇입니다. 질문에 따라 검색량을 조절하고 필요한 근거를 선별했습니다.

[StoryMate](https://github.com/SangMin4973/Story-mate_AI)  
문학 속 인물과 대화하는 독서 서비스입니다. 캐릭터 대화와 퀴즈를 개발하고, 프로젝트 종료 후 검색 품질을 따로 평가했습니다.

[LoadKill](https://github.com/LoadKill/LoadKill-Detection)  
불법 적재 차량 탐지 시스템입니다. 오탐 사례를 분석하고 트럭 탐지와 적재 여부 분류의 역할을 나눴습니다.

## 사용 기술

RAG / LLM: Python, LangChain, ChromaDB, GPT-4o, Qwen3-4B  
Computer Vision: PyTorch, YOLOv8, OpenCV  
Backend / Data: FastAPI, Flask, MariaDB, SQLite, Docker
